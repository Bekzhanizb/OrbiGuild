# Stage 00: Foundation brief

Read [README](../README.md), [PRODUCT](../docs/PRODUCT.md),
[ARCHITECTURE](../docs/ARCHITECTURE.md) and [ROADMAP](../docs/ROADMAP.md).
Implement only the TypeScript/npm foundation, accessible truthful web empty state,
loopback health boundary, strict contracts, meaningful tests, CI and onboarding.

Keep AgentNest unchanged. No source/history import, Electron code, fake agents,
provider calls, databases, execution routes, permissions framework or cloud
resources belong in this stage. Document SQLite as the future default and
user-owned Supabase with Auth/RLS as the maintainer-preferred option.

Verify a fresh install, lint, typecheck, tests and build. Report actual versions,
passed/failed/unavailable checks, limitations, approval decisions and the next two
small steps. Keep changes local unless explicitly authorized to push; never merge
or deploy without approval.
